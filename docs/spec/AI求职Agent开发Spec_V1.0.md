# AI求职Agent开发Spec_V1.0

版本：V1.0

目标： 指导AI求职Agent项目进入实际开发阶段。

------------------------------------------------------------------------

# 1. 开发目标

构建一个垂直领域求职Agent。

核心能力：

-   自动分析岗位
-   自动判断匹配度
-   自动处理HR聊天
-   自动回复
-   自动投递简历
-   后台监听HR消息
-   人工确认关键风险行为

------------------------------------------------------------------------

# Phase 3 MCP接入

## 当前方案

Chrome MCP：

streamable-http

配置：

``` json
{
"type":"streamable-http",
"url":"http://127.0.0.1:12306/mcp"
}
```

## 原则
