# 04 · 会话与消息模块

## 模块说明

`conversations` 对应一个平台 HR 聊天窗口，`messages` 存储聊天消息，`sync_records` 记录每次消息同步批次。会话 ID 规则：Boss ID + 内部 UUID（`uuid` 列），`thread_id` 绑定 LangGraph Checkpoint。

## 表总览

| 表名 | 说明 | 主键 | 关键约束 |
|------|------|------|----------|
| `conversations` | 平台 HR 聊天窗口 | id | UNIQUE(platform, external_id)、UNIQUE(uuid)、UNIQUE(job_id) |
| `messages` | 聊天消息 | id | — |
| `sync_records` | 消息同步批次 | id | — |

---

## 表 1：`conversations`

> 会话模型。Conversation ID 规则：Boss ID + 内部 UUID。`external_id` 存平台侧 ID，`uuid` 为内部生成的 UUID。一个岗位最多对应一个会话（`job_id` 唯一）。

### 字段定义

| 字段 | 类型 | NULL | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `id` | BIGINT | N | autoincrement | 主键 |
| `user_id` | BIGINT | N | — | 所属用户，外键 |
| `platform` | VARCHAR(30) | N | `'boss'` | 平台：boss / lagou / 51job，CHECK 约束 |
| `external_id` | VARCHAR(100) | N | — | 平台侧聊天/会话 ID（同步锚点） |
| `external_chat_id` | VARCHAR(100) | Y | — | 平台侧聊天 ID（新锚点，`external_id` 兼容保留） |
| `uuid` | UUID | N | `gen_random_uuid()` | 内部业务 UUID，唯一 |
| `thread_id` | UUID | N | `gen_random_uuid()` | LangGraph thread_id，默认等于 uuid（1:1） |
| `job_id` | BIGINT | Y | — | 关联岗位，外键，**唯一**（一岗一会话） |
| `hr_id` | BIGINT | Y | — | 关联 HR，外键（迁移 0002 新增） |
| `hr_name` | VARCHAR(100) | Y | — | HR 名称 denorm 冗余（权威在 `hrs`） |
| `job_title` | VARCHAR(200) | Y | — | 岗位标题 denorm 冗余 |
| `status` | VARCHAR(30) | N | `'active'` | 状态：`active` / `waiting_hr` / `closed` |
| `last_synced_at` | TIMESTAMPTZ | Y | — | 最近一次同步时间 |
| `extra` | JSONB | N | `'{}'::jsonb` | 附加字段 |
| `created_at` | TIMESTAMPTZ | N | `now()` | 创建时间（TimestampMixin） |
| `updated_at` | TIMESTAMPTZ | N | `now()` | 更新时间（TimestampMixin） |

### 索引

| 索引名 | 类型 | 列 |
|--------|------|----|
| `ix_conversations_user_id` | NORMAL | `user_id` |
| `ix_conversations_user_status` | NORMAL | `(user_id, status)` |
| `ix_conversations_thread_id` | NORMAL | `thread_id` |

### 约束

| 约束名 | 类型 | 定义 |
|--------|------|------|
| `uq_conversations_platform_external` | UNIQUE | `(platform, external_id)` 唯一 |
| `uq_conversations_uuid` | UNIQUE | `uuid` 唯一 |
| `uq_conversations_job_id` | UNIQUE | `job_id` 唯一（一岗一会话） |
| `ck_conversations_platform` | CHECK | `platform IN ('boss','lagou','51job')` |
| `fk_conversations_user_id` | FOREIGN KEY | `user_id → users.id` |
| `fk_conversations_job_id` | FOREIGN KEY | `job_id → jobs.id` |
| `fk_conversations_hr_id` | FOREIGN KEY | `hr_id → hrs.id` |

### 关联关系

- **N:1** → `users`、`jobs`（`job_id`）、`hrs`（`hr_id`）
- **1:N** → `messages`（`messages.conversation_id`）、`sync_records`、`tasks`、`memory`

### 备注

- `uuid` 与 `thread_id` 两个 UUID：`uuid` 是业务内部标识（对外暴露），`thread_id` 是 LangGraph 状态锚点；ORM 默认两者相同（1:1），但保留可拆分空间。
- `status` 无 DB CHECK 约束（仅在代码中注释约定：`active` / `waiting_hr` / `closed`）。
- 迁移 0002 为会话补挂了 `job_id`、`hr_id`、`thread_id`、`status`、`external_chat_id` 等列及对应索引/约束。

## 表 2：`messages`

> 消息模型。来源（同步系统）：`manual`（用户手动回复）/ `agent`（Agent 发送）/ `history`（页面历史记录）。`external_msg_id` 用于跨来源去重，避免同一 Boss 消息重复入库。

### 字段定义

| 字段 | 类型 | NULL | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `id` | BIGINT | N | autoincrement | 主键 |
| `conversation_id` | BIGINT | N | — | 所属会话，外键 |
| `user_id` | BIGINT | N | — | 所属用户，外键 |
| `role` | VARCHAR(20) | N | — | 角色：`user` / `agent` / `hr` / `system`，CHECK 约束 |
| `content` | TEXT | N | — | 消息正文 |
| `source` | VARCHAR(20) | N | — | 来源：`manual` / `agent` / `history`，CHECK 约束 |
| `external_msg_id` | VARCHAR(100) | Y | — | 平台侧消息 ID（跨来源去重） |
| `sent_at` | TIMESTAMPTZ | Y | — | 实际发送时间 |
| `created_at` | TIMESTAMPTZ | N | `now()` | 入库时间（TimestampMixin） |
| `updated_at` | TIMESTAMPTZ | N | `now()` | 更新时间（TimestampMixin） |

### 索引

| 索引名 | 类型 | 列 | 说明 |
|--------|------|----|------|
| `ix_messages_conversation_sent` | NORMAL | `(conversation_id, sent_at)` | 会话内按时间拉取消息 |
| `ix_messages_user_id` | NORMAL | `user_id` | FK 反查 |
| `ix_messages_external_msg_id` | NORMAL | `external_msg_id` | 平台侧去重 |

### 约束

| 约束名 | 类型 | 定义 |
|--------|------|------|
| `ck_messages_role` | CHECK | `role IN ('user','agent','hr','system')` |
| `ck_messages_source` | CHECK | `source IN ('manual','agent','history')` |
| `fk_messages_conversation_id` | FOREIGN KEY | `conversation_id → conversations.id` |
| `fk_messages_user_id` | FOREIGN KEY | `user_id → users.id` |

### 关联关系

- **N:1** → `conversations`（`conversation_id`）、`users`（`user_id`）

### 备注

- 高频查询模式是「按会话 + 时间倒序翻页」，`ix_messages_conversation_sent` 复合索引直接覆盖，避免 N+1 回表。
- 注意 `updated_at` 存在但业务上消息基本不可变；保留它是为了与 `TimestampMixin` 统一（Mixin 是 mixin，模型仍会生成该列）。
- 去重语义：同一 `(conversation_id, external_msg_id)` 不应重复入库，去重逻辑在 Service 层保证（DB 层未建唯一索引，允许 `external_msg_id` 为空）。

## 表 3：`sync_records`

> 同步记录模型。模式：`initial`（初次）/ `manual`（手动）/ `incremental`（增量）。`messages_synced` 记录本次同步入库消息数。

### 字段定义

| 字段 | 类型 | NULL | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `id` | BIGINT | N | autoincrement | 主键 |
| `user_id` | BIGINT | N | — | 所属用户，外键 |
| `conversation_id` | BIGINT | Y | — | 关联会话（可空，支持全量同步） |
| `mode` | VARCHAR(20) | N | — | 同步模式：`initial` / `manual` / `incremental`，CHECK 约束 |
| `status` | VARCHAR(20) | N | `'running'` | 状态：`running` / `completed` / `failed`，CHECK 约束 |
| `messages_synced` | INTEGER | N | `0` | 本次同步入库消息数 |
| `error` | TEXT | Y | — | 失败原因 |
| `started_at` | TIMESTAMPTZ | Y | — | 开始时间 |
| `completed_at` | TIMESTAMPTZ | Y | — | 完成时间 |
| `created_at` | TIMESTAMPTZ | N | `now()` | 创建时间（TimestampMixin） |
| `updated_at` | TIMESTAMPTZ | N | `now()` | 更新时间（TimestampMixin） |

### 索引

| 索引名 | 类型 | 列 |
|--------|------|----|
| `ix_sync_records_user_id` | NORMAL | `user_id` |

### 约束

| 约束名 | 类型 | 定义 |
|--------|------|------|
| `ck_sync_records_mode` | CHECK | `mode IN ('initial','manual','incremental')` |
| `ck_sync_records_status` | CHECK | `status IN ('running','completed','failed')` |
| `fk_sync_records_user_id` | FOREIGN KEY | `user_id → users.id` |
| `fk_sync_records_conversation_id` | FOREIGN KEY | `conversation_id → conversations.id` |

### 关联关系

- **N:1** → `users`、`conversations`（`conversation_id`）

### 备注

- 同步日志本质是审计型数据：记录「某次同步干了什么、同步了几条」，可据此排查漏同步/重复同步。
- `messages_synced` 与 `messages` 表实际行数不保证强一致（中途失败时部分入库），排查时以 `status` + `error` 为准。
